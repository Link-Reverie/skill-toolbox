## 团队角色与职责

### 🔴 核心团队（高优先级）

#### 1. 类型安全工程师 (Type Safety Engineer)
- **职责**: 修复类型安全问题，增强 TypeScript 类型定义
- **技能要求**: TypeScript 高级类型，泛型，类型推断
- **工时**: 6-8 小时
- **任务**:
  - [ ] 修复 `SkillParser.irToSkill()` 中的 `as any` 类型转换
  - [ ] 为 IR 字段定义正确的类型
  - [ ] 添加编译时穷尽性检查

#### 2. 测试工程师 (Test Engineer)
- **职责**: 补充测试覆盖，确保代码质量
- **技能要求**: Vitest/Jest，单元测试，集成测试，Mock
- **工时**: 12-16 小时
- **任务**:
  - [ ] CLI 命令集成测试
  - [ ] HTTP Source 完整测试（缓存、网络）
  - [ ] Git Source mock 测试
  - [ ] 边界条件和错误场景测试

### 🟡 支持团队（中优先级）

#### 3. 文档工程师 (Documentation Engineer)
- **职责**: 完善文档，提升用户体验
- **技能要求**: 技术写作，API 文档，Markdown
- **工时**: 8-12 小时
- **任务**:
  - [ ] 添加 TypeDoc 自动生成 API 文档
  - [ ] 补充 discovery-source 和 http-source 的 README
  - [ ] 添加更多使用示例和教程
  - [ ] 创建架构决策记录 (ADR)

#### 4. DevOps 工程师 (DevOps Engineer)
- **职责**: 设置 CI/CD 流程，确保持续集成
- **技能要求**: GitHub Actions，npm，CI/CD
- **工时**: 4-6 小时
- **任务**:
  - [ ] 配置 GitHub Actions CI
  - [ ] 添加 npm provenance（供应链安全）
  - [ ] 自动化测试和发布流程
  - [ ] 依赖审计自动化

### 🟢 顾问团队（低优先级）

#### 5. 安全审计员 (Security Auditor)
- **职责**: 代码安全审查，依赖安全
- **技能要求**: Node.js 安全，依赖审计，OWASP
- **工时**: 2-4 小时
- **任务**:
  - [ ] 依赖安全审计
  - [ ] 错误处理安全审查
  - [ ] 输入验证检查
